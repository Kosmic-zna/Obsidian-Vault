## 🖥️ MODULE 1: COMPUTER HARDWARE & THE SYSTEM UNIT

### 1. The System Unit

- **Definition:** A case that contains the electronic components of the computer used to process data.
    
- **Internal Components of a Desktop PC System Unit (6 Items):**
    
    1. Drive bay(s)
        
    2. Power supply
        
    3. Sound card
        
    4. Video card
        
    5. Processor
        
    6. Memory
        
- **The Motherboard:** The main circuit board of the system unit.
    
    - _Slots/Connectors on the Motherboard (3 Items):_
        
        1. Slot for processor chip
            
        2. Slots for memory modules
            
        3. Slots for adapter cards
            

### 2. The Processor (Central Processing Unit - CPU)

- **Definition:** Interprets and carries out the basic instructions that operate a computer.
    
- **Two Main Sub-Components:**
    
    1. **Control Unit (CU):** Directs and coordinates most of the operations in the computer.
        
    2. **Arithmetic Logic Unit (ALU):** Performs arithmetic, comparison, and other operations.
        
- **Processor Variations (Core Counts):**
    
    - Dual-core processor (2 cores)
        
    - Quad-core processor (4 cores)
        
    - Multi-core processor
        
    - Octa-core processor (8 cores)
        
    - Deca-core processor (10 cores, e.g., Intel i9)
        
- **The Four Steps of the Machine Cycle (In Order):**
    
    1. **Fetch:** The Control Unit fetches instructions and data from memory.
        
    2. **Decode:** The Control Unit decodes instructions and sends them to the ALU.
        
    3. **Execute:** The ALU performs calculations or logical operations on the data.
        
    4. **Store:** Results are stored back into memory.
        

### 3. Data Representation & Signals

- **Two Types of Signals:**
    
    1. **Analog Signals:** Continuous signals that vary in strength and quality (Examples: _Soundwaves, thermometers, vinyl records_).
        
    2. **Digital Signals:** Discrete signals representing information using binary values ($0$s and $1$s) (Examples: _CDs/MP3s, digital photos_).
        
- **Binary Digit (Bit) Electronic States:**
    
    - **Binary Digit 1:** Electronic charge present $\rightarrow$ Electronic State: **ON**
        
    - **Binary Digit 0:** Electronic charge absent $\rightarrow$ Electronic State: **OFF**
        

### 4. Computer Memory

- **Definition:** Electronic components storing instructions waiting to be executed, data needed by those instructions, and processing results.
    
- **Three Categories of Items Stored in Memory:**
    
    1. Application programs
        
    2. The Operating System and other system software
        
    3. Data being processed and resulting information
        
- **Two Types of Memory:**
    
    1. **Volatile Memory:** Loses its contents when power is turned off (Example: _RAM_).
        
    2. **Nonvolatile Memory:** Does not lose its contents when power is removed (Examples: _ROM, Flash memory/Flash drives_).
        
- **Memory Capacity Scale (Smallest to Largest):**  
    
    $$\text{Byte} \longrightarrow \text{Kilobyte (KB)} \longrightarrow \text{Megabyte (MB)} \longrightarrow \text{Gigabyte (GB)} \longrightarrow \text{Terabyte (TB)} \longrightarrow \text{Petabyte (PB)} \longrightarrow \text{Exabyte (EB)} \longrightarrow \text{Zettabyte (ZB)} \longrightarrow \text{Yottabyte (YB)}$$
    - **Kilobyte (KB):** $\approx 1$ thousand bytes (Exact: $1,024$ bytes) $\approx 1/2$ page of text
        
    - **Megabyte (MB):** $\approx 1$ million bytes (Exact: $1,048,576$ bytes) $\approx 500$ pages of text
        
    - **Gigabyte (GB):** $\approx 1$ billion bytes (Exact: $1,073,741,824$ bytes) $\approx 500,000$ pages of text
        
    - **Terabyte (TB):** $\approx 1$ trillion bytes (Exact: $1,099,511,627,776$ bytes) $\approx 500,000,000$ pages of text
        
    - **Petabyte (PB):** $1,024$ Terabytes ($1,048,576$ GB)
        
    - **Exabyte (EB):** $1,024$ Petabytes
        
    - **Zettabyte (ZB):** $1,024$ Exabytes
        
    - **Yottabyte (YB):** $1,024$ Zettabytes ($1,208,925,819,614,629,174,706,176$ bytes)
        
- **Three Basic Types of RAM Chips:**
    
    1. Dynamic RAM (DRAM)
        
    2. Static RAM (SRAM)
        
    3. Magnetoresistive RAM (MRAM)
        
- **DRAM Variations:**
    
    - **SDRAM (Synchronous DRAM):** Synchronized to system clock; faster than basic DRAM.
        
    - **DDR SDRAM:** Transfers data twice per clock cycle; faster than SDRAM.
        
    - **DDR2:** Second generation DDR; faster than DDR.
        
    - **DDR3:** Third generation DDR; designed for multi-core processors; faster than DDR2.
        
    - **RDRAM (Rambus DRAM):** Uses pipelining techniques; much faster than SDRAM.
        
- **ROM Varieties:**
    
    - **ROM (Read-Only Memory):** Non-modifiable permanent data and instructions.
        
    - **PROM (Programmable ROM):** Blank ROM chip written to permanently only once.
        
    - **Flash Memory:** Nonvolatile memory that can be erased electronically and rewritten.
        
- **RAM Allocation Recommendations:**
    
    - **2 GB or less:** Basic home/business use, word processing, web communication.
        
    - **2 GB to 8 GB:** Advanced multimedia, accounting/spreadsheets, voice recognition, gaming, video conferencing.
        
    - **8 GB and up:** Power users, CAD design, 3D modeling, professional graphics, website authoring.
        

### 5. Input Devices & Peripherals

- **Definition of Input:** Any data and instructions entered into the memory of a computer.
    
- **Three Forms of Input Instructions:**
    
    1. **Programs:** Series of related instructions telling the computer what tasks to perform and how.
        
    2. **Commands:** Specific user directives that programs respond to.
        
    3. **User Responses:** Instructions issued by replying to questions displayed by a program.
        
- **Enumeration of Input Devices:**
    
    - Keyboard
        
    - Mouse
        
    - Touch screen
        
    - Touch-sensitive pad
        
    - Stylus / Digital pen
        
    - Graphics tablet
        
    - Game controller / Gamepad / Steering wheel
        
    - Microphone
        
    - Webcam / Digital camera
        
    - Scanner (flatbed document scanner)
        
    - Bar code reader
        
    - Optical Mark Recognition (OMR)
        
    - RFID reader
        
    - Magnetic stripe card reader
        
    - Magnetic Ink Character Recognition (MICR) reader
        
    - Biometric device (fingerprint, hand scanner)
        
    - Data collection device
        
- **Device Care Guidelines:**
    
    - Clean computer/device once or twice a year.
        
    - Turn off and unplug before cleaning.
        
    - Use compressed air to blow away dust.
        
    - Use antistatic wipes for exterior case; use cleaning solution and soft cloth for screen.
        

## ⚙️ MODULE 2: OPERATING SYSTEMS (Lesson 8)

### 1. Fundamentals & User Interfaces

- **Definition of Operating System (OS):** A set of programs that coordinates all activities among computer or mobile device hardware.
    
- **Two Types of User Interfaces (UI):**
    
    1. **Graphical User Interface (GUI):** Interact with menus, visual images, icons, and tiles.
        
    2. **Command-Line Interface (CLI):** User types commands represented by short keywords or abbreviations, or presses special keys, adhering to exact spelling, form, and punctuation.
        

### 2. Core Functions of an Operating System (12 Enumerate)

1. Start and shut down a computer or mobile device
    
2. Provide a user interface
    
3. Manage programs
    
4. Manage memory
    
5. Coordinate tasks
    
6. Configure devices
    
7. Monitor performance
    
8. Establish Internet connection
    
9. Provide file management and other device/media tools
    
10. Update operating system software automatically
    
11. Control a network
    
12. Administer security
    

### 3. Power Options

- **Sleep Mode:** Saves open documents and running programs to **RAM**, powers down unneeded functions, and enters a low-power state.
    
- **Hibernate Mode:** Saves open documents and running programs to an **internal hard drive** before completely cutting electrical power.
    

### 4. Program and Task Management

- **Single-tasking vs. Multitasking:** Running one program at a time vs. concurrent processing.
    
- **Foreground vs. Background Applications:**
    
    - **Foreground Application:** The active application currently receiving input and user focus.
        
    - **Background Applications:** Programs running invisibly behind the scenes (e.g., print spooling, network monitors, antivirus).
        
- **Single-user vs. Multiuser:** Single operator system vs. network system serving multiple simultaneous users.
    
- **Task Coordination & Print Spooling:**
    
    - **Print Spooler:** Software that manages print jobs.
        
    - **Buffer:** Temporary holding area on storage media or memory where documents wait.
        
    - **Print Queue:** The line of print jobs waiting to be released to the printer.
        
- **Device Configuration:**
    
    - **Driver:** A small program telling the OS how to communicate with a specific hardware device.
        
    - **Plug and Play (PnP):** Automatic configuration of new hardware devices upon connection.
        
- **Performance Monitor:** Assesses and reports information about computer resources and devices (CPU, Memory, Disk, Network).
    

### 5. Memory Management & Virtual Memory

- **Virtual Memory:** A portion of storage medium (hard drive) functioning as additional RAM.
    
- **The 2 Steps of Virtual Memory Swapping:**
    
    - **Step 1 (Page Swapped Out):** OS transfers least recently used data/instructions from RAM to the **swap file** on the hard drive.
        
    - **Step 2 (Page Swapped In):** OS transfers data/instructions from the hard drive swap file back into RAM when needed.
        

### 6. Ten (10) OS Management Tools (Table 9-1)

1. **File Manager:** Displays files; organizes files in folders; copies, renames, deletes, moves, and sorts files. Creates the illusion of files/folders in memory.
    
2. **Search:** Locates files on device based on specified criteria.
    
3. **Image Viewer:** Displays, copies, and prints graphics file contents.
    
4. **Uninstaller:** Removes a program/app and associated entries in system files.
    
5. **Disk Cleanup:** Searches for and removes unnecessary temporary files.
    
6. **Disk Defragmenter:** Reorganizes fragmented files and unused space on a hard disk for faster access.
    
7. **Screen Saver:** Displays moving images or blanks screen during inactivity.
    
8. **File Compression:** Shrinks file sizes.
    
9. **PC Maintenance:** Identifies and fixes OS problems, repairs drive issues, and improves performance.
    
10. **Backup and Restore:** Copies selected files or entire storage media to another storage location.
    

### 7. Three Main Categories of Operating Systems

1. **Desktop Operating Systems:** Complete OS for desktops, laptops, and tablets.
    
    - **Windows:** Uses Live Tiles, taskbar icons, Recycle Bin, and broad commercial compatibility.
        
    - **Mac OS:** Apple desktop OS; features Dock and Launchpad (opened via `F4` key).
        
    - **UNIX:** Multitasking OS developed in the **early 1970s**.
        
    - **Linux:** Popular, open-source, multitasking UNIX-based OS.
        
    - **Chrome OS:** Linux-based OS designed to work primarily with **web apps**.
        
2. **Server Operating Systems:** Multiuser OS organizing network resources:
    
    - **Windows Server:** Manages applications/sites on-site and in the cloud.
        
    - **OS X Server:** Apple server environment for Mac and iOS client sharing.
        
    - **UNIX:** Handles high-volume transactions and multiple processors.
        
    - **Linux:** Stable and secure; widely used on web servers and supercomputers.
        
3. **Mobile Operating Systems:** Resides on **firmware** of mobile devices and consumer electronics:
    
    - **Android:** Open-source, Linux-based mobile OS designed by Google.
        
    - **iOS:** Proprietary mobile OS developed by Apple exclusively for iPhone and iPad.
        
    - **Windows Phone:** Proprietary mobile OS developed by Microsoft with Live Tiles.
        

### 8. Virtual Machines & OS Security

- **Virtual Machine (VM):** Software-based computer running inside a physical computer (**host**), running its own independent **guest OS** (e.g., Linux VM inside Windows via VMware).
    
- **Securing the OS (5 Best Practices):**
    
    1. Installing only necessary software
        
    2. Configuring users and permissions properly
        
    3. Applying patches and updates
        
    4. Performing regular security monitoring
        
    5. Backups and testing

## 🔒 MODULE 4: DIGITAL SECURITY, ETHICS, AND PRIVACY (Lesson 6)

### 1. Foundational Security Principles

- **Security:** Protection from hostile forces intending to compromise the normal state of being of a system.
    
- **Risk:** Any event or action that could cause a loss of or damage to computer/device hardware, software, data, information, or processing capability. (Risk is taken; security is the goal).
    
- **The CIA Triad (Cybersecurity Pillars):**
    
    - **C - Confidentiality:** Protection of data from unauthorized access or disclosure.
        
    - **I - Integrity:** Ensuring information remains accurate, authentic, and unaltered.
        
    - **A - Availability:** Ensuring timely, reliable access to resources for authorized users.
        

### 2. Seven (7) Categories of Cybercriminals & Threat Actors

1. **Threat Actor:** Formal umbrella term for anyone who maliciously acts upon a computer system.
    
2. **Script Kiddie:** Attackers who want to breach computers but lack technical networking knowledge; they download pre-made hacking tools written by others.
    
3. **Hacker:** Threat actor who breaks through computer security without required permission.
    
4. **Cracker:** Someone who accesses a computer or network illegally with explicit malicious intent to destroy data, steal information, or cause harm.
    
5. **Hacktivist:** A person who gains unauthorized access to files or networks to further social or political causes.
    
6. **Cyberterrorist:** Attackers targeting national computer infrastructure (e.g., power grids) to compromise national security and instill fear.
    
7. **Cyberextortionist:** Demands money or ransom under threat of exposing confidential data, exploiting flaws, or launching attacks.
    

### 3. Cyber Law & Digital Forensics

- **Republic Act 10175 (Cybercrime Prevention Act of 2012):** Philippine law defining cybercrime, providing frameworks for prevention, investigation, suppression, and penalization.
    
- **Digital Forensics:** The discovery, collection, and analysis of digital evidence found on computers, mobile devices, servers, and networks.
    

### 4. Six (6) Common Internet and Network Attacks

1. **Malware:** Contraction of "malicious software"; programs intended to disrupt system security.
    
    - _Case Study: WannaCry (May 2017)_ – Ransomware/worm hybrid affecting hundreds of thousands of computers across 150 countries.
        
2. **Botnet ("Zombie Army"):** A group of compromised computers or mobile devices connected to a network used to attack other systems.
    
    - _Applications:_ Automated troll farms, illegal cryptocurrency mining, DDoS attacks.
        
    - _Case Study: Mirai Botnet (October 2016)_ – Targeted Internet of Things (IoT) devices (cameras, routers) with default factory passwords to crash US internet infrastructure.
        
3. **Denial of Service (DoS / DDoS):** Attack intended to overload a server with network traffic so it cannot provide services to legitimate users. Distributed DoS (DDoS) is carried out via botnets.
    
    - _Case Study: Dyn Attack (2016)_ – Major DNS DDoS outage knocking out Twitter, Netflix, Spotify, Reddit, and PayPal.
        
4. **Backdoor:** A program or set of instructions that allows users to bypass security controls when accessing a program, computer, or network.
    
    - _Case Study: SolarWinds Supply Chain Attack (2020)_ – Backdoor injected into software updates, compromising high-profile enterprise customers.
        
5. **Spoofing:** A technique intruders use to make their network or Internet transmissions appear legitimate to a victim computer or network.
    
6. **Social Engineering:** Gaining unauthorized access or obtaining confidential information by cleverly manipulating human nature, trust, and psychology.
    
    - _Phishing:_ Common social engineering technique tricking victims into revealing passwords or sensitive credentials on fake websites.
        

### 5. Protective Countermeasures & Privacy Controls

- **Protection Against Computer Attacks (8 Safeguards):**
    
    1. Antivirus
        
    2. Firewall
        
    3. VPN (Virtual Private Network)
        
    4. Proper access control
        
    5. Data backups
        
    6. Avoid Evil Twins (rogue Wi-Fi access points)
        
    7. Digital detox
        
- **Information Privacy Measures (5 Methods):**
    
    1. Strong Passwords
        
    2. Two-Factor Authentication (2FA)
        
    3. Biometrics
        
    4. CAPTCHA (Completely Automated Public Turing test to tell Computers and Humans Apart)
        
    5. Encryptions
